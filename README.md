# Imp Translate Web

Companion website for the [Imp Translate](https://github.com/rxliuli/imp-translate) browser extension. Provides text and markdown translation with bilingual paragraph-level comparison.

## Features

- **Text translation** — line-by-line bilingual display with hover-to-compare
- **Markdown translation** — paragraph-level splitting, code blocks preserved untranslated
- Works standalone (Google Translate) or connects to the extension for configured providers

## Development

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
```
